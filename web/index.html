AccessForecast
Conditional Access enforcement preview · report-only what-if

What this does. Point it at a tenant whose Conditional Access policies are running in report-only mode. It reads what Entra has already recorded against real sign-ins and flags every user, device, app and action that would start being blocked the moment you switch those policies to On.

First-time setup — register the app (once)
  1. Entra admin center → App registrations → New registration. Name it Rockfield AccessForecast.
  2. Supported account types: Accounts in any organizational directory (multi-tenant, so it reaches your GDAP clients).
  3. Platform: Single-page application (SPA). Redirect URI — register this exact page's address:
    (open this page over http/https to see its URI)
  4. API permissions → Microsoft Graph → Delegated: Policy.Read.All, AuditLog.Read.All, Directory.Read.All. Grant admin consent.
  5. Copy the Application (client) ID into the field above. Each client tenant consents once (or via GDAP); sign-in logs need Entra ID P1/P2 in that tenant.

Read-only. Nothing is stored on a server; the token lives only in this browser tab. Your Client ID is remembered locally on this device for convenience.

No connection? Drop the two Graph exports (JSON arrays, or full responses with a value array). For a complete read, your sign-in export should include non-interactive + service-principal sign-ins, not just interactive.
